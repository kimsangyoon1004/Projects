# Database

+ The models are defined in the **NBA_AdminSystem\DB_Models\models.py** file, and the **DB_models** is the folder for the Django's models.
+ The **NBA_AdminSystem\djangoStart** folder is used for deal with request from the web. It includes some  flies for url, settings and so on.
+ The **NBA_AdminSystem\NBAadmin** is for the front-end part



# Data Mining

The files and documents for data mining is in the **PageRank** folder.  The following files are all in this folder.

* The source of data is in the **nba.csv** file
* The file for data mining is the **Rank.ipynb**
* The file for insert is the **testInsert.py**
